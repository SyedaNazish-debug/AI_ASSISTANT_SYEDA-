It adjusts the level of concepts explanation based on the students’ understanding and also Uses real-world examples and analogies which makes the concepts more clear.
It also Creates quizzes and practice questions through which students can evaluate their performance and it also helps in improving overtime. 
Reviews answers and provides constructive feedback so they can be more acceptable about their progress..
Helps debug and explain programming code so it also acts as a coding buddy as it can help you pinpoint the loophole in complex problems.
